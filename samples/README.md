# Demonstration fixtures

These five English utterances and Spanish reference translations were authored for this demo. The audio is synthetic speech generated using FFmpeg’s flite/slt voice. No participants or real recordings are included.

Replay outputs are deliberately fixed: baseline examples contain dropped negation, a wrong number and changed uncertainty. Candidate examples match the references. These fixtures test the application workflow only; they are not evidence about any translation model. Replay reports contain no invented inference timings.

For live comparisons choose TextAndOllama (uses textInput) or WhisperAndOllama (uses the WAV). Model names and paths must be configured separately. Review reference translations with bilingual raters before using them in a study. All audio is 16 kHz, mono, signed 16-bit PCM.
